# Avian
<img width="257" height="512" alt="Screenshot 2026-02-03 at 10 19 27" src="https://github.com/user-attachments/assets/56cdea2b-208a-4bc4-a1cf-09bcd015cf25" />

Avian is a RP2350B based flight controller. It uses the BMI270(imu), BMM350(magtomiter), BMP581(pressuer) to potiton itself in the air.

It has 8 PWM pins for fins/control surfaces. 1 I2C bus, 1 SPI bus, and 9 GPIO pins
